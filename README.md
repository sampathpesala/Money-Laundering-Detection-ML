# Money Laundering Detection System using ML and Deep Learning

### MCA Final Year Project - Dr. Abdul Haq Urdu University, Kurnool (2026)

**Problem:** Banks face fraudulent and suspicious transactions. This system detects money laundering patterns.

**Tech Stack:** Python, Pandas, NumPy, Scikit-Learn, MySQL, Jupyter Notebook

**What I Did:**
- Collected and preprocessed financial transaction dataset
- Handled imbalanced data and did feature extraction
- Trained ML models: Random Forest, Logistic Regression for classification
- Implemented basic Deep Learning concepts for accuracy improvement
- Stored flagged high-risk transactions in MySQL backend
- Generated admin reports for suspicious activity

**How to Run:**
1. pip install pandas numpy scikit-learn
2. python app.py

**Future Improvement:** Add real-time transaction monitoring with Flask API.
